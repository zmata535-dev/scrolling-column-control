# Column Width

A Quickshell bar widget for selecting the focused window's width in Hyprland's scrolling layout.

The compact card offers narrow, normal, wide, full-width, and fullscreen actions. Expand the card to customize the three preset percentages. Values are stored in `~/.config/omarchy/column-width.json`.

## Install

Copy this directory to `~/.config/omarchy/plugins/zm.column-width`, add the plugin ID to `plugins` and the bar layout in `~/.config/omarchy/shell.json`, then bind a key with `{ panel = "zm.column-width" }` if desired.
